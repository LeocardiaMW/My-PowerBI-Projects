# Power BI Project

## Overview

This project was completed as part of a Data Technician Bootcamp, focusing on the end-to-end development of interactive Power BI dashboards. The project demonstrates key business intelligence skills including data preparation, transformation, modelling, visualization, and data storytelling using retail and sales datasets. The goal was to transform raw business data into meaningful insights that support informed decision-making.

## Project Objectives

- Clean and prepare retail and sales data for analysis.
- Create an effective data model for reporting.
- Develop interactive dashboards for business users.
- Use DAX calculations to generate meaningful business metrics.
- Apply data storytelling techniques to communicate insights clearly.
- Build visualizations that highlight trends, performance, and opportunities within sales data.

## Skills Demonstrated

### Data Transformation & Cleaning (Power Query)
- Imported data from multiple sources into Power BI.
- Cleaned and transformed datasets using Power Query.
- Handled data quality issues, including formatting inconsistencies and unnecessary fields.
- Applied transformation steps to prepare data for analysis and reporting.

### Data Modelling
- Built relationships between tables to support analytical reporting.
- Created semantic models to improve report performance and usability.
- Structured data to enable accurate calculations and business insights.

### DAX Calculations
- Created calculated columns and measures using Data Analysis Expressions (DAX).
- Developed custom business metrics for sales performance analysis.
- Applied aggregation, filtering, and time-based calculations to enhance reporting capabilities.

### Interactive Dashboard Development
- Designed user-friendly reports with interactive slicers and filters.
- Enabled dynamic exploration of data for different business scenarios.
- Created dashboards that support self-service analytics and decision-making.

### Data Visualization
Developed a variety of visualizations to communicate key insights, including:

- Bar Charts for comparing product and sales performance.
- Line Charts for identifying sales trends over time.
- Pie Charts for category and segment distribution analysis.
- Maps for geographic sales analysis.
- Additional KPI and summary visuals to highlight business performance.

## Data Storytelling

A strong focus was placed on transforming complex datasets into clear and actionable business insights. Visual storytelling techniques were used to:

- Identify sales trends and patterns.
- Compare performance across products, regions, and categories.
- Highlight key business metrics through clear visual design.
- Support data-driven decision-making through intuitive dashboard navigation. 

## Tools & Technologies

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modelling
- Interactive Report Design
- Data Visualization Best Practices

## Key Learning Outcomes

- Improved proficiency in Power BI report development.
- Developed practical experience in data cleaning and transformation.
- Applied DAX to create advanced calculations and business metrics.
- Enhanced ability to design interactive dashboards and visual stories.
- Strengthened analytical skills through retail and sales data exploration.

## Project Outcome

Successfully delivered an interactive Power BI reporting solution that transformed raw retail and sales data into meaningful business insights through effective data modelling, visualization, and storytelling techniques. The dashboard enables users to explore sales performance, identify trends, and make informed business decisions through interactive and visually engaging reports.
